Backup & recovery

Download a consistent snapshot of maps, accounts, settings, sounds, and history.

Restore a backup

Stop the server, keep a copy of the current database and its WAL files, then replace the database with your backup. Remove the old WAL/SHM files only after preserving that copy. Start the server using the same database path.

Forgot the admin password?

On the server computer, run void-rabbit recover-admin USERNAME. Enter a new password at the hidden prompts. It revokes that admin’s sessions.
